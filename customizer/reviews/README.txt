REVIEWS — LOCAL APPROVE WORKFLOW
================================

OPEN EDITOR
  Desktop shortcut: TLC Reviews Approval
  Or double-click: start-reviews-editor.bat
  URL: http://127.0.0.1:8891/

STEPS
  1. A customer submits a review on https://tlcpcrepairs.com/reviews.html
  2. That message is emailed to tlcarder@gmail.com (first time: confirm the FormSubmit email)
  3. Open the editor and paste it into Add a pending review — or test the form while the editor is running
  4. Approve or Reject
  5. Approving rebuilds reviews.html locally
  6. Run deploy-reviews.bat to publish

LIVE
  Page: https://tlcpcrepairs.com/reviews.html
  Submissions never appear until you approve + deploy
